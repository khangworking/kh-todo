# Todo App

A React 18 + TypeScript starter powered by Vite, with ESLint and Vitest + React Testing Library (jsdom).

Requires Node.js 22.12 or later and npm.

```sh
npm install
npm run dev
```

The dev server listens on all interfaces; use the URL printed by Vite.

```sh
npm run build  # Type-check and build into dist/
npm test       # Run tests once
npm run lint   # Check code with ESLint
```

TypeScript strict mode is enabled for the app and Vite configuration. The initial smoke test checks the Todo App heading.
